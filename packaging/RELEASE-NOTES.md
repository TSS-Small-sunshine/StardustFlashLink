## 🛡 本版修复

### ① 自动升级
- **半成品备份自动清理**：备份清单改为原子写；「有目录、无合法清单且超过 1 天」的半成品会被清掉
  （正在备份的新目录不会误删），安装目录的 `backup\` 不再越积越多。
- **升级脚本先语法校验**：回滚脚本 / 健康探针生成后先用随包 Python 跑一遍语法检查，
  模板写坏会**直接中止升级**并给中文原因，而不是等真回滚时才发现。
- **并发升级不再静默丢弃**：抢不到升级锁时界面会看到「另一项升级任务正在进行，本次请求未执行」。
- **熔断可重置**：自动升级连续失败 3 次后不再只能用「删文件」恢复 —— 接口支持 `reset_attempt` 重置。

### ② 配置 / 连接 / 面板
- **配置方案不再「能存不能切」**：保存时就按切换口径校验（检查间隔 5/15/30/60/120、账号留空或纯数字、
  后缀白名单、host 只能是 IP / 域名），不会再出现存进去却永远应用不了的方案。
- **认证网关参数收紧**：配置里的 host 拒绝空格 / 斜杠等字符；网关返回的 `v4ip` / `olmac` 先校验形状，
  坏值不会被拼进登录请求。
- **等待网络可被停止**：服务停止 / 重启时立即结束等待（以前最长要等满 300 秒），等待日志也降噪。
- **状态面板延迟测量加缓存**（30 秒）：不再每次刷新都做 TCP 握手、把请求线程卡住最多 3 秒。
- **日志轮转瞬间不再丢统计**：读日志时若正好撞上轮转，会重试一次。

### ③ 安装 / CI / 批处理
- GitHub Actions 里的输入与分支名改为通过环境变量注入，标题带引号 / `$()` 也不会被当成命令执行。
- PR 机器人支持中文文件名（本仓库主服务脚本是中文名），双线隔离白名单补齐。
- `install.bat` / `uninstall.bat` 括号块里的 `%ERRORLEVEL%` / `%VAR%` 改为延迟展开（不再拿到旧值）；
  卸载时桌面 / 开始菜单路径改为系统实际路径，OneDrive 重定向也能删干净。

## ⚠️ 升级前须知

- **升级不覆盖用户数据**：`config.json`、`password.txt`（含各方案的 `password.<方案名>.txt`）
  与 `logs\` 都保留；安装器只在文件不存在时创建默认值。
- **服务名与安装路径不变**：仍是 `DrcomAutoLogin` 与 `%ProgramFiles%\DrcomAutoLogin`。
- 本版只改内部实现与错误处理，**配置格式与 API 字段没有变化**（仅新增 `reset_attempt` 字段），无需迁移。
