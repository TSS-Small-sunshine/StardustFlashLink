## 🛡 本版修复

### ① 日志面板（用户可感知）
- 单次读取最多 **4 MB**（以前从 offset 一次读到文件末尾，20 MB 日志会整份读进内存）；
  截断点回退到最后一个换行 —— 下一轮从整行边界继续，不会拼出半截行。
- 日志**轮转后**旧 offset 视为失效 → `next_offset` 复位 0：新文件开头的内容不再被永久跳过
  （以前得手动点「刷新」才看得到）。
- 2 秒日志轮询加**请求序号**：慢响应回来时不会把同一段日志重复追加两遍；刷新与在途请求交叉也不再错位。

### ② 前端错误处理与竞态
- 四个 API helper 统一判 **HTTP 状态码**：非 2xx 抛错并带服务端可读原因 —— 不再把
  `{"ok": false}` 当成功、也不再静默吞掉错误（例如日志接口 400）。
- 点「立即登录」**先取状态基线再触发**（then 链），不再出现「刚触发就提示登录已完成」的误报。
- **连点「立即登录」只触发一次**：并发第二个请求立刻返回 `already_in_progress`，
  上一次结束后自动释放 —— 不再让界面空等 120 秒才超时。

### ③ 健壮性与无障碍
- `/api/update/status` 的数值字段改**安全转换**：手改 / 旧版 `config.json` 里的脏值（如字符串）
  不再让接口 500、界面升级块整块空白。
- 配置导入的坏请求文案全部**中文化**（空 body / 缺 `manifest.json` / 格式版本不受支持 / 加密或损坏 zip），
  不再回显英文异常；技术细节只进日志。
- 升级历史 / CHANGELOG 弹窗补**焦点管理**：打开时记住触发元素并把焦点送到关闭按钮，关闭时归还焦点
  —— 键盘 / 读屏用户可以正常使用。

## ⚠️ 升级前须知

  与 `logs\` 都保留；安装器只在文件不存在时创建默认值。
